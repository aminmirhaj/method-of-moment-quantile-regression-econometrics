# Data

This folder contains the datasets used in the empirical analysis of the thesis, covering **111 countries from 2000 to 2021**.

The study examines the relationship between Foreign Direct Investment (FDI), Productive Capacity (PCI), country risk, and resource sustainability, measured by Material Footprint per capita (MFP).

## Data Sources

The datasets were collected from the following sources:

| Data Source | Variables |
|---|---|
| Global Material Flows Database (GMFD) | Material Footprint per capita |
| UNCTAD | Productive Capacity Index (PCI) |
| International Country Risk Guide (ICRG) | Economic, Financial, and Political Risk |
| World Development Indicators (WDI) | Foreign Direct Investment (FDI) and GDP per capita |

## Notes

- `raw/` contains the original source datasets.
- `processed/` contains the datasets prepared for empirical analysis.
- Please refer to the thesis for detailed variable definitions, data sources, and methodology.
